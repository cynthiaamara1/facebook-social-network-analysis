# Facebook Social Network Analysis using NetworkX

## Project Overview

This project analyses a Facebook friendship network using graph analytics and community detection techniques.

The network was constructed from the SNAP Facebook dataset using NetworkX. Several graph measures were computed to understand the network structure, identify influential connections, and detect communities within the network.

---

## Objectives

- Build a social network graph from an edge list
- Explore the structural properties of the network
- Analyse degree distribution
- Identify bridge connections using edge betweenness centrality
- Detect communities using multiple algorithms
- Visualise the network structure

---

## Dataset

Dataset:

Facebook Social Network Dataset (SNAP)

Network statistics:

- Nodes: 4,039
- Edges: 88,234

# Network Analysis

The following network statistics were analysed:

- Number of edges
- Network density
- Average degree
- Degree distribution

---

# Graph Algorithms

## Centrality Analysis

- Edge Betweenness Centrality

## Community Detection

- Girvan–Newman Algorithm
- Label Propagation

---

# Results

Key findings include:

- Sparse network structure
- Hub-like behaviour among highly connected users
- Bridge edges linking different communities
- Multiple friendship communities identified using Label Propagation
- Clear high-level community divisions using Girvan–Newman
